Introducción

Esta guía explica cómo crear un ensamblador y simulador básico para el microcontrolador PIC16F84A, ideal para aprendizaje.

¿Qué vamos a hacer?

  • Entender el PIC16F84A (funciones básicas)
  • Aprender ensamblador PIC (lo esencial)
  • Conocer herramientas para programar
  • Crear un simulador sencillo

¿Para quién es esta guía?

  • Estudiantes de electrónica
  • Programadores que quieren aprender ensamblador
  • Personas interesadas en microcontroladores
  • Docentes que buscan material educativo

PIC16F84A Básico

Características principales

8-bit CPU
1K programa
68 bytes RAM
20 MHz max
1 ciclo por instrucción
13 pines I/O
2 puertos

Partes importantes

  • CPU: Procesa instrucciones (35 tipos diferentes)
  • Memoria programa: Guarda el código (1024 palabras de 14 bits)
  • Memoria datos (RAM): Variables temporales (68 bytes)
  • Puertos A y B: Para conectar LEDs, botones, etc.
  • Timer0: Contador/retardos
  • WDT: Reinicio automático si se bloquea

Registros principales

Registro Función
W Registro de trabajo (acumulador)
STATUS Banderas y control de banco
PC Contador de programa
PORTA/PORTB Puertos de entrada/salida
TMR0 Timer/contador

Ensamblador PIC

Instrucciones básicas

El PIC16F84A tiene 35 instrucciones. Estas son las más usadas:

Mover datos

MOVLW 0x05    ; Cargar 5 en W (W = 5)
MOVWF PORTA   ; Mover W a PORTA (PORTA = 5)

Operaciones

ADDLW 0x03    ; Sumar 3 a W (W = W + 3)
SUBLW 0x0A    ; Restar W de 10 (W = 10 - W)
ANDLW 0x0F    ; AND bit a bit (W = W & 0x0F)

Saltos y llamadas

GOTO etiqueta ; Saltar a etiqueta
CALL subrutina; Llamar subrutina
RETURN        ; Volver de subrutina

Bits

BSF PORTA, 0  ; Poner bit 0 de PORTA en 1
BCF PORTA, 1  ; Poner bit 1 de PORTA en 0
BTFSC PORTA,2 ; Saltar siguiente si bit 2=0

Estructura de un programa

; Programa ejemplo - Parpadeo de LED
; LED conectado a RB0

    ORG 0x0000      ; Empieza en dirección 0
    GOTO INICIO     ; Saltar al inicio

INICIO:
    BSF STATUS,5    ; Ir al banco 1
    CLRF TRISB      ; PORTB como salidas
    BCF STATUS,5    ; Volver al banco 0
    
BUCLE:
    MOVLW 0x01      ; Encender RB0
    MOVWF PORTB
    CALL RETARDO    ; Esperar
    
    CLRF PORTB      ; Apagar RB0
    CALL RETARDO    ; Esperar
    
    GOTO BUCLE      ; Repetir

RETARDO:
    ; Código de retardo
    RETURN
    
    END             ; Fin del programa

Simulador Básico

¿Qué debe hacer un simulador?

  • Leer código ensamblador
  • Ejecutar instrucciones paso a paso
  • Mostrar estado de registros y memoria
  • Simular puertos (entradas/salidas)
  • Mostrar errores si los hay

Partes del simulador

CPU

Ejecuta instrucciones, actualiza registros

Memoria

Almacena programa y datos

Puertos I/O

Simula entradas y muestra salidas

Interfaz

Muestra todo de forma entendible

Ejemplo de código de simulador

// Ejecutar una instrucción
function ejecutarInstruccion() {
    // 1. Leer instrucción
    let instruccion = memoria[PC];
    
    // 2. Decodificar
    let opcode = instruccion >> 7;
    
    // 3. Ejecutar según opcode
    switch(opcode) {
        case 0x00: // NOP - No hacer nada
            PC++;
            break;
        case 0x08: // MOVWF
            let registro = instruccion & 0x7F;
            memoria[registro] = W;
            PC++;
            break;
        // ... más instrucciones
    }
    
    // 4. Actualizar interfaz
    actualizarPantalla();
}

Ejemplos Prácticos

Ejemplo 1: Parpadeo de LED

; LED en RB0 parpadea cada segundo aprox.

INICIO:
    BSF STATUS,5    ; Banco 1
    CLRF TRISB      ; PORTB como salidas
    BCF STATUS,5    ; Banco 0
    
PARPADEA:
    BSF PORTB,0     ; Encender LED
    CALL RETARDO
    BCF PORTB,0     ; Apagar LED
    CALL RETARDO
    GOTO PARPADEA   ; Repetir

RETARDO:
    MOVLW 0xFF
    MOVWF CONT1
RETARDO1:
    MOVLW 0xFF
    MOVWF CONT2
RETARDO2:
    DECFSZ CONT2,F
    GOTO RETARDO2
    DECFSZ CONT1,F
    GOTO RETARDO1
    RETURN

Ejemplo 2: Contador binario

; Contador binario en PORTB (LEDs 0-7)

    ORG 0x00
    GOTO INICIO
    
INICIO:
    BSF STATUS,5    ; Banco 1
    CLRF TRISB      ; PORTB como salidas
    BCF STATUS,5    ; Banco 0
    
    CLRF PORTB      ; Empezar en 0
    
CONTAR:
    INCF PORTB,F    ; Incrementar PORTB
    CALL RETARDO    ; Esperar
    GOTO CONTAR     ; Seguir contando
    
RETARDO:
    ; Código de retardo (similar al anterior)
    RETURN

Ejemplo 3: Leer botón

; Si botón en RA0 está presionado, 
; encender LED en RB0

INICIO:
    BSF STATUS,5    ; Banco 1
    MOVLW 0x01      ; RA0 entrada, otros salidas
    MOVWF TRISA
    CLRF TRISB      ; PORTB salidas
    BCF STATUS,5    ; Banco 0
    
BUCLE:
    BTFSC PORTA,0   ; Si RA0=0 (botón presionado)
    GOTO APAGADO    ; Si no, ir a apagar
    
ENCENDIDO:
    BSF PORTB,0     ; Encender LED
    GOTO BUCLE
    
APAGADO:
    BCF PORTB,0     ; Apagar LED
    GOTO BUCLE
