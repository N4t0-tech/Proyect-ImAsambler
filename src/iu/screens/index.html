ImAsembler

Bienvenido a ImAsembler. Aprende ensamblador para el PIC16F84A mediante lecciones prácticas, un compilador integrado, un simulador visual y minijuegos educativos. Diseñado para estudiantes y docentes, ImAsembler combina teoría y práctica para que programes, simules y entiendas el funcionamiento real del microcontrolador.

📌 Descripción del proyecto

ImAsembler es una aplicación interactiva diseñada para transformar el aprendizaje del ensamblador del microcontrolador PIC16F84A, volviéndolo accesible, dinámico y motivador. A través de una combinación de teoría, práctica y minijuegos educativos, los usuarios pueden adquirir conocimientos sólidos en programación ensamblador mientras se divierten.

El proyecto busca reemplazar el enfoque tradicional —técnico, árido y abstracto— con una experiencia pedagógica moderna basada en:

  • Minijuegos educativos
  • Simulaciones visuales
  • Animaciones interactivas
  • Feedback inmediato
  • Representaciones dinamicas del hardware

La idea principal es que los estudiantes comprendan cómo funcionan las instrucciones ensamblador viendo cómo afectan al microcontrolador en tiempo real

🎮 Características principales

🔧 Simulador visual del PIC16F84A

    Incluye representaciones animadas de:
  • Memoria RAM
  • Registros
  • Contador de programa
  • Puertos de entrada/salida
  • Timer
    • Y muestra cómo cada instrucción modifica estos componentes.

🎮 Minijuegos educativos

    Minijuegos basados en instrucciones reales del PIC, como:
  • MOVLW
  • BTFSC
  • CALL
  • GOTO
  • INCF y DECF
